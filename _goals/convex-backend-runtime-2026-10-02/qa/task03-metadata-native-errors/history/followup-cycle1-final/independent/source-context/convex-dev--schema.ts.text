   1: /**
   2:  * Cortex SDK - Convex Schema
   3:  *
   4:  * Layer 1: ACID Stores
   5:  * - conversations (Layer 1a) - Immutable conversation history (memorySpace-scoped)
   6:  * - immutable (Layer 1b) - Versioned immutable data (TRULY shared, NO memorySpace)
   7:  * - mutable (Layer 1c) - Live operational data (TRULY shared, NO memorySpace)
   8:  *
   9:  * Layer 2: Vector Index
  10:  * - memories - Searchable knowledge with embeddings (memorySpace-scoped)
  11:  *
  12:  * Layer 3: Facts Store
  13:  * - facts - LLM-extracted facts (memorySpace-scoped, versioned)
  14:  *
  15:  * Layer 4: Convenience APIs (SDK only, no schema)
  16:  *
  17:  * Artifacts
  18:  * - artifacts - Interactive versioned documents (memorySpace-scoped, streaming support)
  19:  *
  20:  * Attachments (Multi-modal)
  21:  * - attachments - Multi-modal file storage (images, PDFs, audio, video, files)
  22:  *
  23:  * Coordination:
  24:  * - contexts - Hierarchical context chains (memorySpace-scoped, cross-space support)
  25:  * - memorySpaces - Memory space registry (Hive/Collaboration modes)
  26:  * - agents - Optional agent metadata registry (analytics, discovery, team organization)
  27:  */
