## Concrete findings

1. **Download action loss has no durable lease-expiry wakeup (13A2).** `convex-dev/runtimeMediaJobs.ts:174–183` commits a120-second download lease, but schedules the next action only from `downloadFailed`. A hard action interruption after `claimDownload` bypasses that catch, leaving `downloading` without automatic recovery. Polling stops in that state. Explicit SDK/UI **Recover job status** can recover it, and seven-day expiry can eventually retire it; neither automatically resumes prompt materialization. Schedule a saved-handle recovery wakeup atomically with the lease. Preserve `recoverStoredOutput` before another download, terminal/revocation/expiry guards and the three-attempt bound; never resubmit generation. An older wakeup during a newer third download must respect the active lease before treating the attempt limit as exhausted.

2. **The single poll chain likewise stops on hard action loss (13A2/A4).** `acknowledge` schedules one poll (`runtimeMediaJobs.ts:149–153`); `pollCheckpoint:160–163` increments a counter without committing another wakeup. `runtimeMediaGateway.ts:146–159` schedules the successor only after return/catch through `pollAgain`. If that action is interrupted and the best-effort callback is missed, the job remains `processing` until explicit reconciliation or retention expiry. Add a bounded token/lease-fenced saved-handle watchdog, with normal successful backoff remaining one chain. Stale expiry callbacks must no-op after a newer claim or terminal state. This concerns polling an existing operation, not retrying billable submission.

3. **Official download cost metadata is discarded (13A1/14A1 provenance).** `runtimeMediaGateway.ts:50–53` keeps only bytes/MIME although pinned official provider0.2.1 `src/video-model.ts:252–258` returns `providerMetadata.convexGateway.cost`. Its `src/index.ts:51–64` explicitly preserves numeric Gateway cost. `captureOutput:95–101` already has an aggregate-cost receipt path, but the official adapter cannot reach it. Preserve validated finite nonnegative cost using existing decimal normalization, and attach it only under an actually qualified `gateway-aggregate-usd-v1` terminal-cost contract. Missing/unqualified/invalid cost must retain full conservative uncertainty. Do not infer serving identity from the constructor/model echo, fabricate token usage or change old roots/liabilities. Returned-output rejection/oversize should retain applicable genuine metadata without weakening the byte cap.

4. **Unconfigured async error loses its actionable reason (13A4/14A1 error parity).** `runtimeMediaGateway.ts:77–80` recognizes only messages containing literal `CAPABILITY_UNAVAILABLE`. The documented official error is `Asynchronous video generation is not configured`; the pinned provider propagates its ordinary error message. That falls through to `MEDIA_SUBMISSION_UNKNOWN` after issue, omitting the configuration reason. Recognize the narrow official configuration error as `MEDIA_CAPABILITY_UNAVAILABLE`, while retaining conservative unknown state/cost where appropriate and prohibiting automatic resubmission. This is public error classification, not a refund or a claim that no external effect could occur.

The coordinator has assigned download/poll durability to the existing executor and metadata/error classification to the coordinator, with serialized ownership of the Gateway file. These initial findings remain historical evidence even after the same batch's repairs close.
