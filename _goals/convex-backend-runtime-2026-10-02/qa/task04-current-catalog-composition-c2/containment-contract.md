# Current composition C2 containment contract

Normal CLI: `node current-compose.mjs DESTINATION`. `DESTINATION` must be a strict real descendant of this C2 QA folder or its C2 work/resume folder; every existing lexical ancestor must be nonsymlink. The destination is absent or an empty caller-owned ordinary directory. Preexisting files, symlinks and directory entries reject without writes. Output is never the import/copy workspace.

Before allocation, the runner verifies the fixed SHA256 of its 136-row source manifest and approved additive metadata, exact retained preimage tree, every live source descriptor/bytes/hash, and the complete importable Convex source tree. It captures immutable byte buffers; it does not subsequently copy through live source paths. `readExact` uses lstat ancestors, O_NOFOLLOW, regular single-link descriptors, before/after fstat and ancestor identity recheck. The five-table/16-registration source expectations remain closed.

The runner exclusively allocates a private 0700 workspace and replica, creates each copied file O_EXCL|O_NOFOLLOW mode0600 from its captured buffer, and verifies every private dynamic file, directory and literal dependency link before each trusted child import. All importable Convex files in the live tree must match the pinned list. Unknown dynamic files fail before import; the C1 JS execution attempt remains NOT_REPRODUCED. Installed package reuse is one explicit literal node_modules link, never recursively archived. No dependencies are installed or modified.

All children, including the unchanged historical composer and inventory, execute inside this private workspace with literal nonservice environment and the C2 offline guard. All checked evidence is constructed before publishing eight files. Output files/directories are tracked by dev/ino. Every failure uses finally to remove private allocation and rollback only owned output identities; preexisting caller directories/siblings and late caller files survive. Safe stage/UTC/trusted-child diagnostics are written separately before cleanup. A diagnostic retention failure and an opaque thrown accessor cannot bypass finally. Diagnostics are retained review evidence, not replica residue. Native/import, baseline composer, inventory, copy, tree, and partial-publication errors are controlled and archived.

Guarded supported JavaScript APIs: fetch/WebSocket; HTTP/HTTPS request/get and Agent.createConnection; HTTP2.connect; net.connect/createConnection and Socket.prototype.connect; TLS connect/TLSSocket.prototype.connect; server listen; UDP connect/send/bind. Fresh independent stub transport tests exercise 17 entrypoints with zero transport calls and zero real network. Existing code cannot use an already captured unguarded function, native binding, alternate runtime, or child environment to bypass this protocol; this is not an OS network sandbox. Only the three pinned trusted child commands are run.

Supported threat boundary: trusted repository/workspace ancestry and installed runtime/dependencies; no malicious concurrent process with the same uid renaming those trusted ancestors/private0700 allocations after checks, no compromised runtime/native binding, and a working filesystem permitting cleanup. FD and hash fences detect observed source replacement; immutable buffers prevent source-path copy races. Node does not expose a dirfd/openat capability sandbox here, so universal hostile same-uid race resistance is not claimed. Cleanup failures are surfaced rather than reported successful. The trusted offline-only `composeForControls` seam is not a command-line option and never reads external source roots; it is scoped to this QA/work folder.

No native service, production ledger, root installation, inference, full-core completion or actual test splice is authorized by this contract. Actual model-policy authority remains EMPTY. The proposed four-file patch remains SOURCE_SERIALIZED HOLD pending independent review and ROOT release.
