## Post-purge recovery and late accounting

purgeOwnedPrivate validates all existing lifecycle rows and current account T before building E. Fresh purge supplied evidenceSnapshotHash=H(current E); root evidence receipt snapshot taken before call, drift/new late fact changes E/L hash and returns stale0writes rather than silently purging changed snapshot. Fresh purge retains row.triggerCanonical=T and row.liabilityCanonical=L plus E/before/after/R, then deletes ONLY private stage/evidence/vector, preserving source/chunk/account/lifecycle tombstones/facts. Trigger projection is nontext bounded immutable recovery evidence, so postpurge does not invert an aggregate digest.

Postpurge inspectTrigger/recoverOwnedEvidence: validate installed ROOT ownership, EVERY lifecycle row, current account canonical T/hash/attempt relation. Locate valid applied purge receipt, parse its triggerCanonical, require canonical current T EXACT equals retained purge T and H(T)=R.triggerSetHash. Because no new stage is allowed after purge/closure, this immutable set must remain equal. Check account per-attempt trigger/content/identity hashes against corresponding retained complete TriggerItem. Changed sequence/rawDigest/binding/hashes/canonical/extra or missing trigger yields corrupt denial0writes/no summary. No check against old stored L/current known/reserved/active equality; instead revalidate CURRENT accounting parser/fold/refinement rules separately. Thus legitimate late terminal+money changes current L but leaves T fixed and recovery succeeds with current liabilities. New corrupt monetary state also denies via independent accounting parser, not via trigger equality. Missing StageRow before purge with no valid purge receipt remains corrupt. Exact stage persistence replay AFTER purge returns denied closed; inspect may report retained recorded hashes but cannot reconstruct or reopen private stage bytes.

Late verifyAtCapture backing: existing typed internal observer may supply bounded ephemeral trusted transcript through a verificationBacking union {kind:"retained",transcriptRef:H}|{kind:"transient",transcriptCanonical:string,transcriptHash:H}. Transient canonical<=180000/depth16/nodes4096, exact observer source/dispatch/raw digest match, same closed proof/reducer API rerun, no public caller field. It is not persisted back into purged private tables; validated minimal ReceiptV2/refinement facts may update ONLY original account under historical binding. Missing backing/EMPTY actual proof resolver still unknown/fullK/STOP. This preserves supported late charge/terminal ability without private-byte resurrection, raw endpoint exposure or fabricated actual qualification.
