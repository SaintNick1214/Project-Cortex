```sh
./start-sandbox.sh --help
./start-sandbox.sh --dry-run       # Show the workflow; create nothing
./start-sandbox.sh --no-copy       # Leave the local clipboard unchanged
./start-sandbox.sh --smoke         # Setup, qualification, readiness/HTTP checks, then cleanup
./start-sandbox.sh cleanup SESSION_ID
```

`cleanup` accepts only a generated session UUID and rechecks the owned resource identities. It removes that session's container and database, never other containers/projects or Union Arena resources. The shared sandbox project is retained for later runs. Private scoped keys are removed after successful cleanup; redacted receipts remain in the ignored `.sandbox-env-runs/SESSION_ID/receipts` directory. No Docker prune or unrelated process discovery is used.
