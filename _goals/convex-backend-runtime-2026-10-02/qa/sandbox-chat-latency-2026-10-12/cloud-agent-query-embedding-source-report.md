V6 populated recall now has one private preflight query containing the original current Agent execution/transcript/lease/input checks, read authority, selected profile, readiness, memory-model preparation and both model-policy resolutions. The returned profile, request and model resolutions are tentative data. Fresh admission derives the original request ID, normalized last user text, full profile, semantic identity, ordinal zero and original run budget again. It refuses a supplied binding that selects another principal, budget, source, parent, profile, request or ordinal. The governed model still uses the official Gateway factory and every original middleware request/proof/control check. The private path is integrated only by the V6 owner; generic memory/ingestion callers keep their original ports and behavior.

The memory profile-readiness helper retains its original nested `runtimeModelPolicy:embeddingProfile` query inside the new native preflight. Fresh vector-search readiness and final delivery retain their own profile queries. This batch reduces Action handoffs; it does not claim every native profile call disappeared. The original generic prefix still executes two resolve RPCs (the second was cheap in K18's actual measurements). No estimated savings or causal native speedup is claimed for this source batch.

The native admission parent calls the original `admitHandler`, validates the admitted normalized request, then calls the original checkpoint through **a nested mutation**. If validation or checkpoint refuses after reservation, the parent returns a bounded refusal and commits the original reservation; a throwing child rolls back its own partial writes. The Action rethrows that refusal. This retains the original admission/checkpoint failure-liability boundary: no automatic retry, refund, release, not-dispatched classification or second permit after a lost response. Opaque errors become a bounded refusal without invoking getters or erasing the reservation. Convex documents [child mutation rollback while the parent commits](https://docs.convex.dev/database/writing-data). Controlled tests exercise the same boundary; installed service qualification remains separate.

Terminal evidence capture and private attachment stay separate original operations. Confirmed output with UNKNOWN/full liability can replay under the existing fresh resolution/admission checks without a second provider call. The shared `finishRecallFromEmbedding` helper contains the original post-embedding tail byte for byte: embedding validation; staged vector/fact overlap and vector-first failure priority; ordered bookkeeping commit; result ranking/context; fresh authority/final delivery; and Action-clock expiry. The generic preflight bytes and all other memory-service function bytes match the baseline. The generic Gateway body also matches the baseline after removing only the new optional private port, its type import and its private query branch.
